# Items API

CRUD REST API для управління елементами (items).

## Опис сервісу

Вебсервіс надає REST API для створення, читання, оновлення та видалення елементів (items).  
Кожен елемент має поля: `id`, `name`, `description` (опціональне) та `price`.

### Ендпоінти

| Метод  | URL                | Опис                          |
|--------|--------------------|-------------------------------|
| GET    | `/api/items`       | Отримати список об'єктів      |
| GET    | `/api/items/{id}`  | Отримати об'єкт за ID         |
| POST   | `/api/items`       | Створити новий об'єкт         |
| PUT    | `/api/items/{id}`  | Оновити наявний об'єкт        |
| DELETE | `/api/items/{id}`  | Видалити об'єкт               |

Інтерактивна документація (Swagger UI) доступна за адресою: `http://localhost:8000/docs`

## Мова та фреймворк

- **Мова:** Python 3.12
- **Фреймворк:** FastAPI
- **ASGI-сервер:** Uvicorn

## Збирання та запуск Docker image

```bash
# Збирання образу
docker build -t lab1-api .

# Запуск контейнера
docker run -p 8000:8000 lab1-api
```

Після запуску API доступний за адресою: `http://localhost:8000`

## Запуск тестів

```bash
# Встановити залежності
pip install -r requirements.txt

# Запустити тести
pytest
```
